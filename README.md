# 쌓기나무 놀이터

초등 수학 성취기준 [2수03-02]에 맞춘 브라우저 기반 쌓기나무 활동 웹페이지입니다.

- `dist/` 폴더의 정적 파일을 함께 배포합니다. 첫 화면에서 쌓기나무 개념을 살펴본 뒤 ‘놀이 고르기’로 연습하기, 퀴즈풀기, 작품 만들기 중 하나를 고릅니다.
- 연습과 퀴즈에서는 입체 격자나 블록을 직접 눌러 최대 세 층까지 쌓고, 위에서 보는 화면으로 전환할 수 있습니다.
- ‘쌓기나무 개념’에서 블록의 면과 층, 전체 개수, 기준 블록에서 본 여섯 방향을 그림을 바꾸며 익힙니다. 개념을 살펴본 뒤 하던 놀이로 돌아갈 수 있습니다.
- 기본 블록은 나무색이며 빨간색과 노란색도 선택할 수 있습니다.
- 연습과 별빛 보물찾기에서는 드래그와 방향 버튼으로 쌓기판을 돌립니다. 별빛 보물찾기와 작품의 ‘작품 돌리기’에서는 가로·세로 모두 한 바퀴 돌릴 수 있습니다. 작품은 ‘다시 꾸미기’를 눌러 이어서 편집합니다.
- 별빛 보물찾기의 다섯 단서를 각각 처음 맞히면 1크레딧씩 받습니다. 미술 도구 가게에서 색칠 붓(1), 별 도장(2), 복사 집게(2)를 사서 반복 사용할 수 있습니다. 크레딧과 구입 내역은 같은 브라우저에 저장합니다.
- 작품 만들기에서는 격자 없는 작업판에 블록을 끌어 놓습니다. 가까이 놓으면 윗면이나 옆면에 붙습니다.
- 쌓기 활동 상태는 브라우저에서만 사용하며 서버로 전송하지 않습니다.
- 숲속 별빛 축제에서 토끼의 계단 만들기, 별 다섯 개로 보물상자 열기, 주문을 뽑아 장난감 전시하기를 할 수 있습니다. 받은 도장은 현재 브라우저 탭에서 새로고침해도 유지됩니다.
- 각 놀이에서 자신이 만든 모양을 보며 기준 블록과 이웃 블록의 위치를 말합니다. 화면은 선택한 방향이 실제 배치와 맞는지 확인하고, 학생이 전체 모양을 설명했다고 확인하면 도장을 줍니다. 실제 구술은 짝이나 교사가 듣고 관찰합니다.
